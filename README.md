# polimuli — полиарт-мульты

Каталог проектов **полиарт-мультфильмов**: каждый мульт — это отдельный
мини-фильм или сериал в Canvas 2D, со своим визуальным языком, собранным
из **эмодзи-направлений** (эмодзи служат арт-подсказкой, а не только
рисунком персонажей).

Первый мульт в серии — «Пирожки с нуля» (кулинарный, Шеф Вишенка).
Ниже — 95 мультов, по статье на каждый: `articles/NN_*.txt`.

## Принцип эмодзи-направления

Один мульт = один словарь эмодзи — «визуальная подсказка», из которой
собираются формы, палитра, персонажи, задники и частицы. Словари намеренно
выходят за привычные категории (лица/тела/транспорт/архитектура/природа):
используются базы значков ПДД, строительных работ, бытовых, офисных,
музыкальных, медицинских и прочих.

```

courses/                       — серии-курсы в формате POL (index.html → выбранный курс)
```

## Формат POL

Весь каталог (№16–95, 80 эпизодов) переведён на формат POL — декларативный
JSON: акты (сценарий с фоном), акторы (эмодзи с keyframes/покачиванием/циклами),
частицы, стиль HUD и подписей. Спека — `spec/spec-format-pol.md`.
Просмотр: открой `player/player.html#?pol=...` или `player/player.html?src=/episodes/16_express_strela.pol` —
либо упакуй в автономный файл:

```
node pack/polimuli_pack.js episodes/16_express_strela.pol   # → *_packed.html
```

## Курсы (серии в формате POL)

Идея: 1,5-часовой вебинар дисциплины режется на модули, и каждый модуль
получает короткий полиарт-урок (24 с) по единому шаблону
`ТЕМА → ПРИМЕР → ПРАКТИКА → ИТОГ`. См. `courses/`. Пилоты:
«Физика невесомости» (`courses/fizika-nevesomosti/`) и «Полиарт-метод»
(`courses/polyart-metod/`) — в уроках работает лектор-профессор 🧑🏫
и доска конспекта (`style.board` + `acts[].board`, спека — `spec/`).

## Университет полиарта

Весь процесс обучения «от зачисления до выпуска» — в `university/`:
регламент учебного заведения (`kuhnya-obucheniya.txt`), программа семестра
и годовая программа начальных курсов (md), гипотетический набор 2026,
а также описание метода в txt / md / pdf.

## Пайплайн производства

Для каждого мульта применяется общий конвейер:

1. **Идея** — логлайн, жанр, аудитория.
2. **Эмодзи-направление** — словарь подсказок и база значков.
3. **Стиль** — палитра, техника рисования, фирменные эффекты.
4. **Персонажи** — пропорции, цвета, анимационные позы.
5. **Серии** — структура эпизода, тайминг-эвенты.
6. **Режиссура** — камера, монтаж, звук, музыка, темп.
7. **Продюсирование** — софт-стек, график, сценарный менеджмент.
