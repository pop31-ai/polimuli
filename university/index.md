# 🎓 УНИВЕРСИТЕТ ПОЛИАРТА

Образование навыками через полиарт: **1 курс = 1 лекция-видеоролик (≈1.5 ч),
подаётся частями по графику** — лекция с лектором-профессором → полиарт-урок →
семинар → конспект → проверка. Полный маршрут: **от зачисления до выпуска**.
