# 🎓 УНИВЕРСИТЕТ ПОЛИАРТА · ПРОГРАММА СЕМЕСТРА

Формат: **одна полнокровная лекция (≈1.5 ч) = один курс**, который подаётся
ЧАСТЯМИ по графику: лекция-профессор → полиарт-урок → семинар → проверка.
Каждый модуль недели — одна «порция» исходного видеокурса.

---

## График недели (шаблон)

| День | Формат | Что происходит |
|------|--------|----------------|
| Пн | 🧑🏫 Лекция с доской | Лектор-профессор ведёт тему, набрасывает конспект на доску (по строке) |
| Вт | 📺 Полиарт-урок (24 с) | Рекап лекции: тема → пример → практика → итог, в финале вопрос-практика ❓ |
| Ср | 🍵 Семинар | Разбор задач по теме лекции, ответ на вопрос полиарт-урока |
| Чт | ✍️ Конспект | Студент сводит доску лектора + рекап эпизода в свой конспект |
| Пт | ✅ Проверка | Короткий тест по модулю (порог 60/100), фиксация баллов |

Итог: 16 недель × 5 форматов = недельный ритм из **одной лекции-видеоролика,
режется на порции**, каждая порция проходит путь «смотрю → повторяю → думаю → пишу → сдаю».

---

## Дисциплина-пример: «Физика невесомости» (семестр в 4 модуля)

| Недели | Модуль | Лекция-источник | Полиарт-урок |
|--------|--------|-----------------|--------------|
| 1–4 | Падение без опоры | «Лифт рвёт трос — что чувствует пол?» | n01 Свободное падение |
| 5–8 | Орбита как вечное падение | «Почему спутник не падает на Землю» | n02 Орбита |
| 9–12 | Парабола-комета | «25 секунд невесомости в самолёте-горке» | n03 Парабола-комета |
| 13–16 | Жизнь на орбите | «Вода, пламя, мышцы — как живёт невесомость» | n04 Жизнь на орбите |

Каждый полиарт-урок = файл `courses/fizika-nevesomosti/n0X_*.pol`,
самосборка `n0X_*_packed.html` (работает из file://, пауза по клику/пробелу).

---

## Оценки и аттестация

- Модуль: 100 баллов = полиарт ❓ (30) + семинар (40) + конспект-тест (30).
- Зачёт по курсу семестра: среднее по 4 модулям ≥ 60/100.
- Экзамен: итоговый полиарт-эпизод-билет; защита личной мини-серии (3–5 эпизодов).

## Курсы семестра (начальный поток)

1. 🧑🚀 Физика невесомости — готова (4 урока).
2. 💡 Полиарт-метод — вводный: как устроен конвейер (5 уроков).
3. 📐 Математика-инженер — пределы, производные (план, серия в производство).
4. 🛠️ Информатика-«почини движок» — алгоритмы и устройство POL (план).
