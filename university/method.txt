# ПОЛИАРТ-МЕТОД · ОПИСАНИЕ (vers. 1)

Полиарт — способ переложить лекцию/курс на серию коротких
эмодзи-эпизодов (формат POL). Движение материала: СМЫСЛ → КАДР.

## 1. Ядро метода

- 1 курс = 1 исходный видеоролик (лекция ≈1.5 ч).
- Курс режется на МОДУЛИ (по неделям семестра).
- Каждый модуль = один полиарт-урок (24 с) по шаблону:

    ТЕМА (at 0) → ПРИМЕР (at 6) → ПРАКТИКА/вопрос ❓ (at 12, вопрос виден 18–24) → ИТОГ (at 18)

- Подача части: лекция с лектором-профессором + доска для конспекта
  → полиарт-урок → семинар → конспект студента → проверка.

## 2. Формат данных POL (JSON)

- Эпизод: duration (сек), style (hud/подписи/доска), acts[], actors[].
- Акты: { at, text, bg, board[] } — текст-заголовок, фон, строки доски.
- Акторы: { id, emoji, x, y, size, key[] (at/x/y/size), visible, эффекты }.
- Эффекты движения: bob (покачивание), sway (волна), pulse (биение).
- visible — только на уровне актора: true/false/{from,to}.
- Доска: style.board {x,y,w,h,bg,frame,text,font,step}, act.board =
  массив строк; строка i появляется при t ≥ at + i*step (запись мелом).
- Кадр: canvas 960×540.

## 3. Конвейер производства курса (7 шагов)

1. ИДЕЯ — логлайн, жанр, аудитория.
2. ЭМОДЗИ-НАПРАВЛЕНИЕ — словарь значков темы.
3. СТИЛЬ — палитра, эффекты, доска.
4. ПЕРСОНАЖИ — лектор 🧑🏫 и фишки серии (пюпитр 🎤).
5. СЕРИИ — структура модулей, тайминг (акты 0/6/12/18).
6. РЕЖИССУРА — темп, ритм, вопросы-практика.
7. ПРОДЮСИРОВАНИЕ — валидация (exit 0/1/2), упаковка _packed.html,
   публикация в индекс курса.

## 4. Проверка и сборка

- node pack/polimuli_pack.js <file.pol|dir> — exit 0 ok / 1 warn / 2 error.
- Сборка автономна: engine+runtime+JSON инлайн, работает из file://.
- Плеер: player/player.html?src=/episodes/….pol или ?pol=<json>.
- Пауза: клик по холсту или пробел. ctrl: pause/resume/stop.

## 5. Роли

Лектор-профессор (ведёт серию), семинарист (практика), куратор потока,
методист (резка курса на модули), инженер POL (движок/упаковка/валидация).
