ПОЛИАРТ-УНИВЕРСИТЕТ
КУХНЯ ОБУЧЕНИЯ: ОТ ЗАЧИСЛЕНИЯ ДО ВЫПУСКА
(документ проекта polimuli · версия 1)
========================================================================

1. КРАТКО
------------------------------------------------------------------------
Университет полиарта готовит навыки через СЕРИИ КОРОТКИХ ПОЛИАРТ-УРОКОВ
(формат POL, эмодзи-анимация, ~24 секунды на урок) в связке с лекциями
и семинарами. Любой большой курс (математика, физика, «починить
движок») — это ОДИН ОБЪЁМНЫЙ ВИДЕОКУРС, который подаётся ЧАСТЯМИ
по графику: лекции с лектором-профессором → полиарт-уроки → семинары.

Ниже — вся «кухня» такого обучения: от набора абитуриентов до выпуска.

2. ПРИНЦИП: КУРС = ОДИН ВИДЕОРОЛИК ЧАСТЯМИ ПО ГРАФИКУ
------------------------------------------------------------------------
- Курс описывается как единый контент (1,5 часа лекций исходно).
- Он режется на МОДУЛИ (по неделям семестра).
- Каждый модуль живёт по единому шаблону:
      ЛЕКЦИЯ (лектор + доска для конспекта)
        → ПОЛИАРТ-УРОК (рекап 24 с, формат POL)
        → СЕМИНАР / ПРАКТИКА (задачи по теме)
        → ПРОВЕРКА (вопрос из урока, разбор).
- Полиарт — «клей» между лекцией и практикой: анонс, рекап, мнемоника,
  шпаргалка, задание.

3. ЭТАП 0. НАБОР И ЗАЧИСЛЕНИЕ
------------------------------------------------------------------------
[Поток абитуриентов — гипотетический, пример для набора 2026]
- Кампания: открытые полиарт-заставки курса как «витрина» факультета.
- Заявление: анкета + мотивационное эмодзи («напиши свою тему-лого»).
- Вступительная диагностика: 3 полиарт-эпизода с вопросами (❓) —
  определяет стартовый уровень по шкале 0–100.
- Зачисление: распределение по потокам (группам 8–12 человек),
  выдача «зачётной книжки» (POL-объект ученика с трекером прогресса).
- Результат этапа: официальный приказ о зачислении (документ + POL-открытка).

Пример потока (гипотетический набор 2026, факультет «Физика невесомости»):
  группа ФН-01: Иван, Мария, Алекс, Дина, Пётр, Соня, Лев, Анюта
  группа МА-01: Глеб, Вера, Тимур, Алиса, Роман, Зоя, Марк, Яна

4. ЭТАП 1. ВВОДНЫЙ МОДУЛЬ
------------------------------------------------------------------------
- «Как учиться здесь»: правила, график, инструменты (плеер, галерея,
  сборки HTML из file://, локальный сервер).
- Знакомство с форматом POL: что такое акты, акторы, частицы, доска.
- Пробный эпизод «Полиарт-метод: Идея» — первый конспект на доске.
- Сдача вводного теста — пропуск на семестр.

5. ЭТАП 2. ГРАФИК СЕМЕСТРА
------------------------------------------------------------------------
Семестр = 16 недель. Неделя = один модуль курса.

  ПН   ЛЕКЦИЯ (лектор + доска): теория, конспект.
  ВТ   ПОЛИАРТ-УРОК: рекап 24 с, вопросы-практика.
  СР   СЕМИНАР: разбор задач, мозговой штурм по теме.
  ЧТ   САМОСТОЯТЕЛЬНАЯ РАБОТА: сборка своего микро-эпизода POL.
  ПТ   ПРОВЕРКА: тест/ответ на вопрос эпизода (❓).
  СБ/ВС ВЫХОДНОЙ + «добор» для отстающих.

Годовая программа начальных курсов (пример, 2 семестра):
  Семестр 1: Полиарт-метод (как это делается) + Введение в физику
             (механика: начиная с невесомости).
  Семестр 2: Математика для инженера (пределы, производные) +
             Информатика: «как чинить движок» (основы, алгоритмы) +
             Итоговый проект.

6. ЭТАП 3. УРОК (внутренняя «кухня» одного модуля)
------------------------------------------------------------------------
- Лекция ведётся ЛЕКТОРОМ-ПРОФЕССОРОМ (единый персонаж серии,
  эмодзи-аватар на кафедре) — он набрасывает материал на ДОСКУ
  для конспекта (записи появляются строкой за строкой).
- Полиарт-урок (POL): акты «ТЕМА → ПРИМЕР → ПРАКТИКА → ИТОГ»,
  лектор + микрофон, доска, вопрос-практика (эмодзи ❓) в финале.
- Каждый урок закрыт автономной сборкой `_packed.html` (работает
  из file://) — студенту ничего ставить не нужно.

7. ЭТАП 4. ОЦЕНИВАНИЕ
------------------------------------------------------------------------
- Баллы: за ответы в полиарт-эпизодах, задачи семинара, тесты.
- Зачёт по модулю: порог 60/100.
- Экзамен: итоговый эпизод-экзамен серии (вопросы + билеты).
- Академическая история: файл студента, полиарт-инфографика прогресса.

8. ЭТАП 5. ИТОГОВЫЙ ПРОЕКТ
------------------------------------------------------------------------
- Студент делает СОБСТВЕННУЮ мини-серию в формате POL (3–5 эпизодов):
  применяет весь метод на своей теме.
- Защита: показ сборок + рассказ «как я это собрал» (лектор комментирует).
- Работы принимаются в каталог курсов проекта (как новые серии).

9. ЭТАП 6. ВЫПУСК
------------------------------------------------------------------------
- Набор требований выполнен → допуск к выпуску.
- Выпускной акт: итоговый полиарт-эпизод «диплом» (личный, с эмодзи
  выпускника), файл-сертификат.
- Учёт выпускников, алфавит alumni-серии (каталог работ).
- Выпускник может стать лектором нового потока (петля «студент → профессор»).

10. РОЛИ (КУХНЯ ПО ЗА КУЛИСАМИ)
------------------------------------------------------------------------
- ЛЕКТОР-ПРОФЕССОР: ведёт серии, пишет конспекты на доске.
- СЕМИНАРИСТ: разбирает практику, проверяет задачи.
- КУРАТОР ПОТОКА: следит за прогрессом, «доборы» отстающим.
- МЕТОДИСТ: режет 1,5-часовой курс на модули по шаблону.
- ИНЖЕНЕР POL: упаковывает сборки, проверяет валидность (exit 0/1/2),
  поддерживает движок/рантайм/плеер.

11. ТЕХНОЛОГИИ (инструменты проекта)
------------------------------------------------------------------------
- Формат POL (JSON): акты, акторы, частицы, стиль, доска.
- Движок + рантайм: canvas-воспроизведение, ctrl.pause/resume/stop,
  клик/пробел — пауза.
- Упаковщик: `node pack/polimuli_pack.js file.pol|dir` → автономная
  сборка `_packed.html` (exit 0/1/2, работает из file://).
- Плеер: `player/player.html?src=/episodes/….pol` или `?pol=JSON`.
- Галереи: `episodes/pol_index.html`, `courses/index.html`.

12. КОНВЕЙЕР МАССОВОГО ПРОИЗВОДСТВА КУРСОВ
------------------------------------------------------------------------
Любой 1,5-часовой вебинар превращается в курс за 7 шагов:
  1. ИДЕЯ — логлайн, жанр, аудитория.
  2. ЭМОДЗИ-НАПРАВЛЕНИЕ — словарь значков темы.
  3. СТИЛЬ — палитра, эффекты, доска.
  4. ПЕРСОНАЖИ — лектор, гости, «фишки» серии.
  5. СЕРИИ — структура модулей, тайминг.
  6. РЕЖИССУРА — камера, монтаж, темп, вопросы.
  7. ПРОДЮСИРОВАНИЕ — график, упаковка, контроль качества.

13. ПРИМЕР РАБОЧЕЙ СЕРИИ (уже в репозитории)
------------------------------------------------------------------------
- courses/fizika-nevesomosti/ — «Физика невесомости»: 4 урока
  (свободное падение, орбита, парабола-комета, жизнь на орбите).
- courses/polyart-metod/ — «Полиарт-метод»: 5 уроков
  (идея, сценарий-данные, движение, серия, упаковка).
- В каждом уроке: лектор-профессор + доска для конспекта.
