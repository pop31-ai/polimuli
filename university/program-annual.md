# 🎓 УНИВЕРСИТЕТ ПОЛИАРТА · ГОДОВАЯ ПРОГРАММА НАЧАЛЬНЫХ КУРСОВ

**Принцип:** каждый курс — один исходный видеоролик (лекция ≈1.5 ч),
подаваемый частями по графику семестра. Каждая порция = лекция-доска →
полиарт-урок (24 с) → семинар → конспект → проверка.

---

## I СЕМЕСТР (16 недель) · вводное ядро

**Курс 1 — «Полиарт-метод»** (готов: p01–p05)
- Цель: понять конвейер «лекция → эпизоды POL → серия».
- Модули по 2–3 недели: идея и направление → сценарий-данные → движение
  смыслов → серия и модуль → упаковка и запуск.
- Итог семестра: студент собирает свою мини-серию (3 эпизода) с лектором.

**Курс 2 — «Физика невесомости»** (готов: n01–n04)
- Цель: один сюжет механики от быта к орбите.
- Модули: падение → орбита → парабола-комета → жизнь на орбите.

**Курс 3 — «Математика для инженера»** (план)
- Начала анализа: пределы → производная → интеграл → модель движения.
- Каждый модуль = полиарт-эпизод по шаблону ТЕМА→ПРИМЕР→ПРАКТИКА→ИТОГ.

**Курс 4 — «Информатика: устройство POL»** (план)
- JSON, акты/акторы, стиль; валидация (exit 0/1/2); сборка _packed.html.

## II СЕМЕСТР (16 недель) · практикум и проект

- Недели 1–8: разбор реальных кейсов проекта (cases/), доработка галереи,
  мини-практики «переписать лекцию в серию».
- Недели 9–16: **итоговый проект** — студент выпускает собственную серию
  5–8 эпизодов на выбранную тему («свой универ»), защита перед лектором.
