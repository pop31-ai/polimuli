🎬 polimuli — инструкция «полиарт-ролик в HTML»

Полиарт-ролик — это мини-мульт на Canvas 2D, нарисованный эмодзи: фон-акты, персонажи-акторы, частицы, подписи. Три способа полут дистрибутива:

СпособЧто за файлыГде лежитРаботает из file://
Пилоты (написаны кодом)*.htmlepisodes/✅ да
POL-эпизоды (данные + рантайм)*.pol + плеерepisodes/*.polчерез ?pol= или сборку
Собранные (самодостаточные)NN_*_packed.htmlepisodes/✅ да

1. Самый быстрый путь — открыть галереи

Пилоты 01–15: открой episodes/index.html — каждая карточка ведёт в рабочий HTML-ролик. Открывается по двойному клику, без сервера.
POL-эпизоды: открой episodes/pol_index.html — карточки ведут в NN_*_packed.html (движок + рантайм + данные уже внутри файла).

3. Просмотр произвольного .pol через плеер

Плеер — player/player.html. Он подключает движок и рантайм и читает данные из адресной строки или встроенного объекта.

3.1. Через HTTP (если есть локальный сервер)

player/player.html?src=episodes/16_express_strela.pol

Плеер сделает fetch файла и при ошибке покажет сообщение (коды: fetch failed, не формат pol, нет данных).

3.2. Из file:// (без сервера) — закодированный JSON

Локальный fetch из file:// в большинстве браузеров запрещён (CORS), поэтому для file:// данные передают прямо в URL шифрокодом:

player/player.html?pol=%7B%22format%22%3A...%7D

Без сервера проще всего пользоваться готовыми сборками NN_*_packed.html — они созданы специально для file://.

3.3. Встроенный датасет __POL_DEMO__

Если в странице перед плеером объявить

<script>window.__POL_DEMO__ = { "format":"polimuli/pol", "version":1, ... };</script>

плеер проиграет эти данные без всякого сервера. Так собирает файлы упаковщик.

4. Упаковка .pol в самодостаточный HTML

Упаковщик — Node CLI без зависимостей. Он проверяет данные по спеке и кладёт движок+рантайм+JSON инлайн в одну HTML-страницу, которая открывается из file://.

node pack/polimuli_pack.js episodes/16_express_strela.pol
# → создаст episodes/16_express_strela_packed.html

node pack/polimuli_pack.js episodes/          # упаковать все *.pol в папке
node pack/polimuli_pack.js a.pol -o out.html  # указать имя результата
Код выходаЗначение
0ок, файл собран (могут быть предупреждения-артефакты)
1собрано, но были предупреждения проверки
2ошибки валидации — файл не собран
⚠ Упаковщик проверяет: маркер "format":"polimuli/pol", версию, canvas.w/h, наличие актов, сортировку acts[].at, ссылки particles[].from на существующих акторов, метраж ключей. Ошибка печатается как ERR : файл — причина.

5. Создать свой ролик за 10 минут

Полная спека — spec/spec-format-pol.md. Минимум, чтобы ролик заработал (minimal viable .pol):

{
  "format": "polimuli/pol",
  "version": 1,
  "meta":   { "id": "demo", "title": "Мой ролик", "dur": 24 },
  "canvas": { "w": 960, "h": 540 },
  "acts": [
    { "at": 0,  "text": "СЦЕНА ОДНА", "bg": { "top": "#203a60", "bottom": "#0c1528" } },
    { "at": 12, "text": "СЦЕНА ДВА", "bg": { "top": "#503020", "bottom": "#241008" } }
  ],
  "actors": [
    { "id": "герой", "emoji": "🐱", "x": 480, "y": 380, "size": 80,
      "bob": { "amp": 6, "speed": 1.2 },
      "key": [ { "at": 0, "x": 180 }, { "at": 12, "x": 780 } ] }
  ],
  "particles": [
    { "from": "герой", "dy": -30, "emoji": "✨", "rate": 0.1,
      "vy": -20, "life": 1.2, "size": 16 }
  ]
}
СекцияЧто значит
meta.durдлина ролика в секундах (цикл)
acts[]сцены: at время старта, text подпись, bg градиент неба
actors[]эмодзи-спрайты: bob/sway качание, pulse пульс размера, cycle смена эмодзи, key[] движение x/y/size по времени, visible {from,to} окно видимости
particles[]частицы от актора (from) или точки: скорость, жизнь, размер, прозрачность
styleцвета HUD и подписи {hud, caption}

Правила «ухо востро» (валидность данных)

  • "format" и "version":1 обязательны.
  • key[] задаёт только x, y, size. Видимость — только на уровне актора, не внутри ключей.
  • Время ключей — в пределах 0 … meta.dur.
  • Сортасцируй acts[] по at (или рантайм отсортирует сам).
  • Эмодзи должны быть обычными Юникод-эмодзи (льв, герб, символы).
  • Проверяй паковщиком: node pack/polimuli_pack.js my.pol — 0 в ответ = ок.

6. Быстрый чек-лист запуска

✅ Открыл episodes/index.html — смотрю пилоты.
✅ Открыл episodes/pol_index.html — смотрю POL-сборки.
✅ Хочу свой файл → написал my.pol → упаковал → открыл my_packed.html.
✅ Хочу данные в чужом приложении → встраиваю polimuli_engine.js + polimuli_runtime.js и зову Polimuli.play(данные, 'id').

7. API одной строкой

const ctrl = Polimuli.play(data, canvasIdOrEl);
ctrl.pause();   // стоп кадра
ctrl.resume();  // продолжить
ctrl.stop();    // остановить

Плеер также вешает клик на холст (пауза/продолжить), а упакованные сборки дополнительно слушают Space.
